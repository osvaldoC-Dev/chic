# Bamba1 · Site do Salão Chic Hair Camama

Site e landing page do Salão Chic Hair, no Camama, Luanda. HTML, CSS e JavaScript simples, sem instalação.

## Ficheiros

- `index.html`: site completo (serviços, trabalhos, marcação, como chegar)
- `landing.html`: landing page curta para o link do Instagram
- `styles.css`: estilos partilhados pelas duas páginas
- `main.js`: botões de WhatsApp e formulário de marcação
- `config.js`: números de WhatsApp e mensagem padrão
- `images/`: fotos dos trabalhos

## Ver no computador

Abra `index.html` ou `landing.html` no navegador.

## Marcação por WhatsApp

Os botões abrem o WhatsApp com a mensagem de marcação já escrita (serviço, dia e hora). A cliente só precisa de carregar em enviar. Para mudar os números ou a mensagem padrão, edite `config.js`.

## Por preencher

- Preços dos serviços (aparecem como `[preço] Kz`)
- Dias de funcionamento, na secção "Como chegar"
- Oferta para novas clientes, na faixa da landing page

## Publicar online (grátis)

No GitHub, vá a Settings → Pages, escolha a branch `main` e a pasta `/ (root)`. O site fica em `https://osvaldoC-Dev.github.io/Bamba1/` e a landing em `.../landing.html`.
